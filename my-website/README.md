# Games Review Page

This website is for Gamers or people interested in getting into games and will include reviews about games and the overview of them 

## Files
- index.html: Home page
- about.html: About page
- catalogue.html: catalogue page
- suggestions.html: susggestion page with the form
- css/style.css: the one stylesheet used by every page
- js/script.js: the JavaScript functions
- images/: pictures used on the site

## How to open
Download or clone this repository, then open index.html in a web browser.
